# 掌中界 · 空间画布 v0.5

这是“掌中界”Windows 无限工作桌布的可运行原型。v0.5 增加了 Windows 原生桌面宿主：React 负责无限画布，WebView2 承载界面，`IExplorerBrowser` 承载真实 Windows Shell 文件视图。

## 已实现

- 外层与子画布均支持中键平移、普通滚轮以指针为中心缩放。
- 鼠标所在的最深层画布自动获得滚轮控制权，移出边界立即切回上一层。
- 子画布中的普通元素可以在一次拖拽中连续跨越 `L3 → L2 → L1`；松手所在画布成为新的归属，视觉尺寸与抓取位置保持不变。
- 跨层移动时显示不受画布裁切的全局浮动影子，并提示将释放到哪张画布；这是移动引用，不复制真实文件。
- 非活动子画布在短暂空闲后隐藏两排顶部工具栏，替换成轻量静默缩略图；鼠标靠近或点击时恢复完整画布。
- 普通同层元素靠近后水滴吸附，松开生成下一层子画布。
- 两个已有画布从顶部“拖动融合”区域靠近时，会出现明显的水滴连接、目标呼吸光和“松开融合”提示；松手后合并成同一层的一张大画布，不会额外增加层级。
- 也可以 `Shift` 多选两个同层画布，然后点击浮动工具栏中的“融合画布”。
- 子画布拥有独立坐标、缩放、固定栏和整理能力，并可以继续吸附生成下一层。
- 画布最多三层；第三层会显示“最深层”并阻止继续生成第四层。
- 空间导航器显示所有画布的父子关系、当前层级、元素数量和缩放比例。
- 可移动、自由缩放的子画布、网页视频、文件夹、便签、参考图板和应用门户卡片。
- 万能固定栏与新增内容菜单。
- 空白区域框选、`Shift` 多选，以及多选后自动出现的组合栏。
- 二分屏、三分屏、四宫格和主次布局。
- 二分屏支持左右 `1:1`、上下 `1:1`、左右 `2:1`、上下 `2:1`；生成后拖动中间分隔条可继续调整比例。
- 双击任意子画布标题栏，可在掌中界工作区内最大化该视口；再次双击或点击恢复按钮，精确回到最大化前的位置与尺寸。
- 最大化视口的左、右、上、下四条边线均可向内拖动，分别创建左右或上下分屏；松手前显示半透明分屏预览。
- 新分屏区域可选择现有画布、网页、文件夹或空白画布；中间分隔线可继续拖动改变比例。
- 退出最大化只恢复外框几何，最大化期间创建的内部分屏与内容继续保留，并随会话自动保存。
- 最大化标题栏提供真正全屏入口；运行环境不支持 Fullscreen API 时自动使用应用内容全屏，`Esc` 返回应用内最大化。
- 最大化时原位置只保留轻量几何占位，不重复渲染内部画布，避免额外 CPU/GPU 开销。
- 任意画布元素成组 / 解组；成组后整体移动。
- 窗口弹出并置顶，置顶内容不随画布移动。
- 点击网页窗口后由它独占声音状态。
- `Space` 超级预览、`Ctrl + Z` 撤销。
- 自动保存，并在再次启动时询问恢复或打开默认桌布。
- 深色、浅色、跟随系统三种主题。
- 双击文件夹入口可在桌面版中打开“此电脑”的原生 Shell 文件视图，保留真实文件操作与系统右键能力。
- 超级预览左侧显示从“此电脑/磁盘”到当前文件的完整目录树；右上角提供“收藏”和“打开位置”。
- 收藏可选择当前文件或所在文件夹，只保存引用，不移动真实文件。
- 超级预览支持双击内容打开、双击空白返回，以及双击鼠标滚轮返回预览起点。
- 最大化/恢复可反复切换；中键松开、指针取消、窗口失焦或离开后强制终止平移状态。

## 本地运行

```powershell
npm install
npm run dev
```

默认开发地址由 Vite 输出。生产构建使用 `npm run build`。

## Windows 桌面版

首次构建会把 WebView2 SDK 下载到本项目的 `.packages` 目录，不会全局安装开发组件：

```powershell
npm run desktop:build
npm run desktop:run
```

也可以直接运行：

```powershell
& '.\native\bin\x64\Release\掌中界.exe'
```

桌面宿主以普通用户权限运行，不替换 `explorer.exe`，不安装驱动、服务或 Explorer 扩展。

## 升级提示

- 网页卡片现使用独立的 `BrowserWebView2` 用户资料目录，以支持与掌中界界面不同的网页颜色策略。首次从旧版升级后，网页账号需要重新登录一次；书签映射和掌中界项目不受影响。
- 若网页专用环境无法启动，程序会自动借用应用 WebView2 环境进入“兼容模式”。网页仍可打开，但强制深色在本次启动中可能不生效，重启后会再次尝试专用环境。
