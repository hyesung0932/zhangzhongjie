掌中界 · 使用手册

把网页、文件夹、便签当成一张张草纸摆在画布上 —— 随手拖、随手推开、一键存成模板。

30 秒上手（只要这三下）

  1. 鼠标移到卡片上 → 上方浮出标题栏 → 按住标题栏就能拖动卡片。
  2. 在空白画布上右键 → 新建便签 / 新建网页 / 新建文件夹（想放什么就放什么）。
  3. 想一键开工：左栏点「模板」 → 选一张（或先用「保存为模板」把现在的画布存下来）。

一、界面地图

位置是什么
最左边竖栏工具栏：新建、网页、文件夹、便签、待办、模板、设置（齿轮 / Ctrl+,）
顶部画布名、搜索框（Ctrl+K：搜网址 / 搜磁盘）、保存、模板、最近使用、截图
中间大片画布：卡片就摆在这里。空白处右键出菜单。
右下角当前画布名、层级 L1、缩放百分比
右侧（点开）空间导航器：列出所有卡片和子画布，点一下就能定位

二、画布操作

  • 缩放：滚轮（以鼠标位置为中心）。
  • 平移：按住鼠标中键拖动，或按住空格拖。
  • 框选：在空白处按住左键拉框。
  • 多选：Ctrl 点选，或 Ctrl+A 全选。

三、拖动卡片：两种手感

① 推开草纸（白板风专属）

设置 → 画布风格选 白板风（浅色） 或 白板风（深色） 之后： 拖着卡片去撞别的卡，挡路的卡会让开一条缝；你松手或者往回拖，它不会弹回原处。

  • 往左推，左边的卡往左让；同一次拖动里再往右推，右边的卡往右让 —— 不会互相盖住。
  • 竖着推同理：往上推，上面的卡往上让。
  • 默认的「深色玻璃」皮肤不会推开挡路的卡（这是设计如此）。

② Ctrl + 拖标题栏 = 拖出一份副本

按住 Ctrl 再拖标题栏，原件和邻居都不动，只有副本跟着鼠标走。

③ 靠近就会吸

把卡片拖到另一张旁边（或叠上）会提示对齐 / 融合，松手就贴齐；两张网页卡叠在一起会融合成一个子画布。

四、卡片类型

类型用途 & 小技巧
便签记一句话。点一下就能改字；空便签会自己消失。
待办清单带勾选框，套用模板时勾会清零（每天从没打勾开始）。
网页卡真实网页窗口。可缩放、可静音；Ctrl+滚轮在卡内缩放网页。
文件夹卡就是一个文件夹窗口。可以直接拖文件进去。
子画布两张网页卡叠一起就融合成一层；右下 HUD 显示 L1/L2 层级。
参考板 / 图片卡放参考图、PDF，拖进来即可。

五、模板：一键开工

  • 存：左栏「保存画布为模板」（或卡片右键 → 保存现在的画布为模板），起个名字。
  • 用：左栏「模板」→ 浮层里选一张 → 进入画布。浮层顶部有搜索框，模板多了也能秒找。
  • 改：从模板开出来的画布，改完再存会问你「覆盖更新 / 另存为新模板」。
  • 开机自动：模板浮层底部勾「开机自动套用默认模板」，下次打开直接进那张画布。

七、看着不舒服就调这两处

  • 字太小：设置 → 界面字号 → 小 / 标准 / 大 / 特大（整站等比放大，画布、面板、卡片标题都会跟着变）。
  • 白底上字看不清 / 想要深色：设置 → 画布风格 → 白板风（浅色）/ 白板风（深色）/ 默认（深色玻璃）。

八、数据在哪 / 换电脑

  • 所有数据都在 %LOCALAPPDATA%\掌中界（会话、模板、缩略图、剪贴历史）。卸载不会删，想恢复出厂就删掉这个文件夹。
  • 换电脑：装好程序，把这些文件夹拷过去即可：Templates（模板）、Session（上次的画布）、settings.json（设置）。
  • 单张画布要给别人：卡片右键 → 导出参考板 / 打包到目录。

九、常见问题

现象原因 / 处理
拖卡片撞别的卡，为什么不让开？只有「白板风」皮肤会推开挡路的卡；默认深色玻璃不会。去设置换皮肤。
网页卡 / 文件夹卡打开很慢卡里是真实的窗口，第一次打开要几秒，之后会缓存。
桌面没有图标重装一次，安装时把「创建桌面快捷方式」勾上（1.0.94 起默认已勾选）。
字还是小设置 → 界面字号 → 特大；再配合系统显示缩放。
提示缺少 WebView2安装器会自动装（那一步要联网）；也可手动装微软的 WebView2 运行时。
