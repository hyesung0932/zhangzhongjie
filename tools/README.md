# tools/

掌中界用到的几个小工具与辅助程序。

| 东西 | 是什么 | 源码在仓库里吗 |
|---|---|---|
| `generate_app_icon.py` | 生成应用图标（`native/resources/app-icon.*`） | ✅ 在，Python 脚本 |
| `ScreenCapture.exe` | 区域 / 全屏截图，配合全局快捷键把截图落进「剪贴暂存」 | ❌ 独立的小工具，仓库暂未包含其源码，安装包里带二进制 |
| `ImageReader.exe` | 截图工具的标注 / 长截图 / 取色，以及 OCR 取字的入口 | ❌ 同上 |
| `ocr/RapidOCR-json/` | 离线 OCR 引擎（第三方，Apache-2.0） | ❌ 第三方发布物，安装包里带运行时 |
| `ui-motion-src/` | 参考用的动效样例 HTML（非本项目代码） | ❌ 未收录，作者与许可不明 |

所以：**只 clone 本仓库可以构建出掌中界本体**（画布、卡片、网页、文件夹、模板、皮肤都正常），
但「区域截图 / 截图工具 / OCR 取字」这几个入口需要安装包里附带的 `tools/` 二进制才能用。
用安装器装（Releases 里的安装包）是完整体验。
